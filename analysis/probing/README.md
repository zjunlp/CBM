# probing

Belief probing experiment scripts extracted from `analysis/`.

This directory is for post-answer belief-probe workflows only. Depth/noise
diagnostics live in the sibling `analysis/depth_and_noise/` package.

## Layout

```text
analysis/probing/
├── scripts/
│   ├── build_belief_probe_dataset.py
│   ├── run_belief_probe_ranking.py
│   ├── export_simple_belief_probe_cases.py
│   └── archive/      # Historical plotting scripts
└── outputs/        # Generated by scripts by default
```

## Workflow

Build probe prompts from selected case trajectories:

```bash
python analysis/probing/scripts/build_belief_probe_dataset.py \
  data/task_a/9B/test/failed_stay \
  --scenario a
```

Run ranking probes:

```bash
python analysis/probing/scripts/run_belief_probe_ranking.py \
  --input analysis/probing/outputs/belief_probe_dataset_task_a.json \
  --output-dir analysis/probing/outputs/task_a/9B/probing/base
```

Export compact case-level JSON for manual inspection:

```bash
python analysis/probing/scripts/export_simple_belief_probe_cases.py \
  --input analysis/probing/outputs/task_a/9B/probing/base/probe_ranking_results.json \
  --output analysis/probing/outputs/task_a/9B/probing/base/probe_ranking_simple_cases.json
```

`run_belief_probe_ranking.py` still imports the shared model backend from
`utils.llm_backend` at the project root.
